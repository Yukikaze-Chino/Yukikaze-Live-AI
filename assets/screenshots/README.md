# Screenshots

Place repository-safe screenshots here. Recommended names:

- `banner.png`: repository header image, 1600 x 700 or wider.
- `control.png`: control panel and TTS settings.
- `live-overlay.png`: caption, dialogue and music-log overlays in a live layout.
- `memory.png`: short-term and long-term memory page.
- `music.png`: BiliNCM collaboration view.

Before committing, crop browser tabs, API keys, Bilibili account details, room IDs, local paths, private chat messages, QR codes, and notification banners.
