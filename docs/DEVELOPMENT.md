# 开发状态与路线

## 已具备

- B 站事件接收和网页聊天镜像。
- AI 自动回复、离线测试聊天、上下文查看。
- 短期/长期记忆及可回滚的总结记录。
- GPT-SoVITS TTS 队列、人工与 AI 独立配置。
- 字幕、发言框、BiliNCM 日志三个浏览器源。
- MCP 搜索、BiliNCM 与 VoiceMeeter 可选协作。

## 后续方向

- 更多直播事件源的实测与兼容性报告。
- 更灵活的媒体源/显示器视觉输入选择。
- 可导入导出的公开配置模板。
- 面向贡献者的 Windows 安装诊断。

提交改动前请保持模块独立：B 站、AI、TTS、记忆、字幕与音乐集成的故障不能相互拖垮。
