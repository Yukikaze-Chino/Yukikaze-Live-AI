# 架构说明

## 模块边界

| 模块 | 责任 | 故障隔离 |
| --- | --- | --- |
| `bili-receiver` / `bili-sender` | 直播事件、网页聊天镜像、可选真实弹幕 | 断线时不停止 TTS 和字幕 |
| `ai-*` | 角色回复、上下文、记忆、工具调用 | AI 或搜索失败时保留本地台词工具 |
| `tts-*` / `reply-queue` | 合成、顺序队列、播放时序 | 单句失败不应堵塞后续字幕和队列状态 |
| `public/*` | 控制台、字幕、发言框、日志浏览器源 | 浏览器源断开不应停止后端 |
| `music-collaborator` / `voicemeeter-router` | BiliNCM 状态和音频路由 | 外部程序未启动时禁用该集成 |

## 记忆数据流

```text
事件 → 短期事件库 → 上下文筛选 → AI 回复
                      ↓
                自动总结/人工编辑
                      ↓
                  长期记忆库
```

短期记忆关注当前直播情景，长期记忆保存稳定偏好、常聊话题和经过确认的重要事实。角色设定优先于两者。

## 为什么拆分浏览器源

`/caption`、`/dialogue` 和 `/log-overlay` 独立输出，直播姬可以分别放大、裁剪、隐藏或换样式。音频播放位于控制台，避免字幕源重复播放同一句语音。
