# Third-party Components

This repository integrates with or references the following independently maintained projects and services:

- GPT-SoVITS for optional local speech synthesis.
- Model Context Protocol SDK for MCP connectivity.
- WaveSurfer.js for audio-waveform editing.
- BiliNCM-TS for optional music request collaboration.
- VoiceMeeter for optional Windows audio routing.

Their binaries, accounts, cookies, models, music catalogues, and licenses are not included here. Install and use each component under its own license and service terms.
