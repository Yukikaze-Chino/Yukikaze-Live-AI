# 视觉素材与发布边界

## 仓库内包含的素材

- `assets/brand/`：README 头图与项目识别图。
- `assets/showcase/`：用于说明雪风直播氛围、角色方向和画面效果的压缩展示图。
- `assets/stream-kit/rainy-night/`：无字雨夜直播组件，适合在直播姬或 OBS 中继续排版。
- `assets/screenshots/`：供使用者补充自己的安全截图；不包含个人账号和真实直播资料。

素材整理与公开页面署名：**雪风智乃**。B 站主页：<https://space.bilibili.com/23547595>。
